COMO CONFERIR

O sistema não está respondendo?

Verifique se o Web Service do Render está no ar, se o Wokwi está em execução e se o DEVICE_TOKEN configurado no Wokwi é exatamente igual ao do Render. O CONTROL_TOKEN é uma segunda chave, usada apenas no painel.

Se o ESP32 aparecer offline, consulte o Monitor Serial do Wokwi: respostas HTTP 401 indicam token incorreto e falhas negativas de HTTP costumam indicar problemas de rede ou tempo de resposta. /api/health valida apenas o servidor, não o dispositivo.
